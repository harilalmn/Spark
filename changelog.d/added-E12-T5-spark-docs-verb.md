`spark docs` brings the help the application shows under F1 to the terminal: with no arguments it
lists every topic, `--topic ID` prints one as Markdown, and `--out DIR` writes them all as `.md`
files for publishing or for reading with no Spark installed.

It is the same library the window shows rather than a second copy, so a node installed this session
has a page and a node that does not exist has none.
